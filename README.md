HOW TO SHARE REPORTS AUTOMATICALLY (Google Drive Setup)
=========================================================

This lets everyone on the team see the same reports automatically —
no more emailing files back and forth or losing track of the latest version.

ONE-TIME SETUP (do this once on each computer)

1. Make sure Google Drive Desktop is installed and you're signed in on this
   computer. If not, get it here: https://www.google.com/drive/download/

2. Agree on ONE shared Google Drive folder the whole team will use for
   reports. If someone already made one, ask them to share it with you
   in Drive (same as sharing any Google Doc). If not, create a folder
   in Drive and share it with your teammates.

3. Open SoilReporter.

4. In the left sidebar, near the bottom, find the small folder icon
   next to "Reports folder" and click it.

5. A window will pop up asking you to choose a folder. Go into your
   Google Drive folder and select (or create) a folder there — for
   example, a folder called "ASTE Reports."

6. It will ask to restart SoilReporter. Click yes — it reopens on
   its own in a few seconds.

That's it. From now on, any report you or a teammate creates or edits
will show up for everyone within a few seconds — as long as everyone
did this same setup pointing at the SAME Drive folder.

A FEW THINGS TO KNOW

- Do this on every computer that should share reports with the team.
- Everyone needs to be added to the shared Drive folder by whoever
  owns it before this will work for them.
- It can take a few seconds for a change to show up on someone else's
  screen — that's normal, not a bug.
- Don't rename the Reports folder itself once it's set up.
- If something looks wrong or reports seem to be missing, don't
  delete anything — just ask for help before making changes.
